# Mission 1 — Follow information through a computer

## 1. Task / objective

Trace input, processing, output and storage in one activity. Identify examples of hardware, software and other computer-based systems.

## 2. Work completed

Calculated 36 + 17 in the shell. The result was displayed, saved to a plain-text file and read back to confirm it was stored.

## 3. Commands / tools used

Shell arithmetic evaluated the expression. `printf` displayed the number, the shell's output redirection saved it, and `cat` read the saved file.

## 4. My understanding

### Input, processing, output and storage

| Stage | What happens in the calculation | Component |
| --- | --- | --- |
| Input | The expression `36 + 17` is entered into the shell. | Keyboard |
| Processing | The shell evaluates the addition and keeps the result in memory. | CPU and RAM |
| Output | The terminal displays `53`. | Display |
| Storage | The result is written to a text file, which can be read again later. | SSD |

The same computed number goes to the display and to a file. The saved file remains available after the current shell session ends.
